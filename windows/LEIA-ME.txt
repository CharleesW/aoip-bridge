AoIP Bridge para Windows (versao de teste 0.7.0)
===============================================

ATENCAO: versao de teste. A janela unica (0.7.0) foi testada no Mac e ainda NAO rodou no
Windows. Salve seus projetos antes e nao use em culto ou evento antes de testar.

O QUE VEM NO PACOTE
- Um programa so, "AoIP Bridge", numa janela propria (usa o Edge do Windows, sem barra de
  navegador): Rede (Controller) | Mesa | Placa virtual | Diagnostico.
  Inicia com o Windows e fica com um icone perto do relogio (duplo clique abre a janela).
  Fechar a janela NAO para o audio.
- Placa virtual SEMPRE LIGADA. Sem nenhum programa de audio usando a placa, ela nao manda
  nada para a rede (volta sozinha quando o REAPER abre).
  Clique no icone para:
    - Canais: 2x2, 4x4, 8x8, 16x16, 32x32 ou 64x64
    - Latencia: 64, 128, 256 ou 512 amostras
    - Taxa: 44,1 kHz ou 48 kHz (a rede e sempre 48 kHz; 44,1 e convertido)
    - Capturar som do Windows: o que o Windows estiver tocando vai para a rede num fluxo
      a parte, fora da matriz, chamado "NOME-DO-PC - Saida de Audio" (2 canais)
    - Iniciar com o Windows
    - Abrir o AOIP-Bridge / Sair
- Driver "AoIP Bridge ASIO": a placa AoIP no REAPER (e outros programas de 64 bits).
  Ele so leva o audio entre o REAPER e o programa; se o programa estiver
  fechado, o driver abre ele sozinho.
- Mesa: liga uma placa de verdade (ex.: Ui24R) a rede. Na janela: Mesa > "Ligar a mesa".
  Dali em diante ela liga com o Windows e volta sozinha se cair. Para parar: "Desligar a
  mesa", embaixo a esquerda.

COMO INSTALAR
1. Feche o REAPER. Extraia o ZIP inteiro para uma pasta (nao rode de dentro do ZIP).
2. De dois cliques em "Instalar.bat" e aceite o pedido de administrador.
   - Se aparecer "O Windows protegeu o computador" (programa sem assinatura), clique em
     "Mais informacoes" e depois "Executar assim mesmo".
3. Tudo fica em C:\Program Files\AoIP Bridge. O programa ja abre no fim da
   instalacao (icone perto do relogio; pode estar escondido na setinha "^").

COMO USAR NO REAPER
1. Options > Preferences > Audio > Device.
   Audio system: ASIO.  ASIO Driver: AoIP Bridge ASIO.
2. Os canais e a taxa sao os escolhidos no icone perto do relogio. Se voce mudar la com o
   REAPER aberto, o REAPER reabre a placa sozinho.
3. Janela (duplo clique no icone, ou "ASIO Configuration..." no REAPER). A primeira parte,
   "Rede (Controller)", mostra TODAS as maquinas com o AoIP na rede (Windows e Mac) e liga
   qualquer canal de qualquer maquina em qualquer entrada de outra, de qualquer painel.
   Clique no nome da maquina para abrir/fechar; com as duas fechadas, clicar no cruzamento
   liga 1 para 1. O lapis (lapis) ao lado do canal renomeia: "Ch 01 Bumbo".
   A parte "Placa virtual" tem o resto:
   - "Enviar para a rede": as linhas "Entrada 1, 2..." sao as SAIDAS do REAPER.
     Os fluxos enviados se chamam "NOME-DO-PC Virtual : 1", ": 2"... (8 canais cada).
   - "Receber da rede": escolha os fluxos e ligue os canais; eles chegam nas ENTRADAS
     do REAPER (AoIP Entrada 1, 2...).
   - Mudou algo em Configuracao? Vale na hora (a rede religa em ~1 s).
4. O Firewall do Windows e liberado pelo instalador (UDP 319, 320, 5004, 8793, 9875 e,
   para o Controller, TCP 8791 e 8792 so da rede local).

LIMITES DESTA VERSAO (importante)
- O AoIP NAO aparece na lista de saidas de som do Windows (caixas/fones): isso exige um
  driver de sistema assinado pela Microsoft. Para mandar o som do Windows para a rede,
  use "Capturar som do Windows" no icone.
- No Dante Controller o AoIP Bridge aparece so como TRANSMISSOR de fluxos AES67 (regra do
  Dante Controller). As ligacoes entre os nossos programas sao feitas no painel.
- So aparelhos Dante com "AES67 Mode" ligado conseguem ouvir os fluxos do AoIP Bridge.
- So programas de 64 bits. Use cabo de rede: por Wi-Fi o audio falha.

ATUALIZACOES
O AoIP procura versoes novas no GitHub ao abrir e a cada 6 horas. Quando houver, aparece
"Atualizar para vX" no topo do painel (e no menu do icone). Ao clicar, ele baixa, confere o
arquivo e abre o instalador: feche o REAPER antes e aceite o pedido de administrador.
Para desligar: Placa virtual > Configuracao > "Procurar atualizacoes no GitHub".

PARA REMOVER
Feche o REAPER e rode "Desinstalar.bat" (em C:\Program Files\AoIP Bridge).
